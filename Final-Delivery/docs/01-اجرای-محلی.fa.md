# اجرای محلی وب‌سایت و ربات بله

## پیش‌نیاز
- Python 3.11 (در لینوکس تست شده). در ویندوز: `py -3.11` (نسخه‌ی 3.14 برای نورا توصیه نمی‌شود).
- Git اختیاری است؛ این بسته ZIP است.

## ۱. خارج‌کردن فایل‌ها
ZIP را در پوشه‌ای بدون فاصله و غیرفارسی استخراج کنید، مثلاً `C:\nora\`.

## ۲. ساخت محیط پایتون (لینوکس/macOS)
```bash
cd nora
python3.11 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r website/nora-ui/backend/requirements-dev.txt -r bale-bot/nora_bot/requirements.txt
```

## ۲ب. ساخت محیط پایتون (ویندوز PowerShell)
```powershell
cd nora
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r website\nora-ui\backend\requirements-dev.txt -r bale-bot\nora_bot\requirements.txt
```
(این مسیر روی ویندوز تست نشده است.)

## ۳. اجرای تست‌ها (بدون توکن واقعی)
لینوکس:
```bash
PYTHONPATH=website/nora-ui .venv/bin/python -m pytest -q website/nora-ui/backend/tests
cd bale-bot && PYTHONPATH=. ../.venv/bin/python -m pytest -q nora_bot/tests
```
ربات باید بدون `BOT_TOKEN` هم تست‌ها را اجرا کند؛ اگر متغیرهای محیطی قبلی دارید، آن‌ها را خالی کنید.

## ۴. اجرای وب‌سایت
```bash
cp website/nora-ui/.env.local.example website/nora-ui/.env.local   # فقط روی لپ‌تاپ خودتان
.venv/bin/uvicorn --app-dir website/nora-ui backend.app:app --host 127.0.0.1 --port 8000
```
سپس در مرورگر `http://127.0.0.1:8000/` را باز کنید. برای ورود مالک و داده‌ی آزمایشی، راهنمای `LOCAL-DEVELOPMENT` ابزار `tools/local-dev.py` را ببینید (در بسته‌ی فعلی تحویل داده نشده؛ اگر لازم شد، بگویید).

## ۵. اجرای ربات
1. `bale-bot/nora_bot/.env.example` را به `.env` در همان پوشه کپی کنید.
2. `BOT_TOKEN`، `SUPER_ADMIN_ID` و سایر مقادیر را فقط در `.env` محلی بگذارید (راهنمای `03`).
3. اجرا:
```bash
cd bale-bot
../.venv/bin/python -m nora_bot.main
```
توقف: `Ctrl+C`. لاگ‌ها را در همان ترمینال می‌بینید.

## ۶. ارتباط وب و ربات
ربات برای ارتباط با API به `NORA_SHARED_API_URL` و `NORA_BOT_SERVICE_TOKEN` نیاز دارد؛ همان راز باید در بک‌اند (`NORA_BOT_SERVICE_TOKEN`) تنظیم شده باشد. اگر هر دو یکی نباشند، درخواست‌ها رد می‌شوند.

## ۷. عیب‌یابی
- خطای `ModuleNotFoundError`: مطمئن شوید از پوشه‌ی درست و با PYTHONPATH اجرا می‌کنید.
- خطای `database_not_configured` (503): `NORA_DATABASE_URL` تنظیم نشده است؛ برای اجرای محلی SQLite یا PostgreSQL لازم است.
- ربات بالا می‌آید ولی پاسخ نمی‌دهد: `BOT_TOKEN` را بررسی کنید و مطمئن شوید فقط یک نمونه از ربات در حال اجراست.
