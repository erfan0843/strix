# اتصال وب‌اپ نورا، Mini App و ربات بله

Mini App همان وب‌اپ موجود است؛ روی دامنهٔ HTTPS خود سامانه باز می‌شود و رابط وب دومی نیست. رابط گفت‌وگویی ربات هم باقی می‌ماند: منوی قدیمی و مسیرهای رویداد، فرم، پروفایل، حضور، دعوت، اعلان و پشتیبانی حذف نشده‌اند.

## اتصال داده

- در مسیرهای مشترک این فاز، وب‌اپ و ربات از API واحد FastAPI و پایگاه دادهٔ سرور استفاده می‌کنند؛ کد نصب و وابستگی‌هایشان جداست. همهٔ ماژول‌های قدیمی ربات هنوز از SQLite منتقل نشده‌اند.
- پیش از ساخت پایگاه محلی قدیمی، ربات API را با هویت سروری می‌سنجد و `SUPER_ADMIN_ID` را باید در backend به‌عنوان مالک (`NORA_OWNER_BALE_USER_ID`) شناسایی کند؛ قطع API یا شناسهٔ مالک ناهماهنگ، اجرا را می‌بندد.
- `nora_bot/shared_api.py` برای هویت سروری، کارتابل مشترک پروفایل و فیش، فرم‌های منتشرشده و پاسخ‌های مشترک، پیوست خصوصی، فایل محتوای منتشرشده و اعلان‌ها به API وصل می‌شود. تاریخچهٔ فرم‌های کاربر و گزارش فقط‌خواندنی مدیر هم از همین منبع خوانده می‌شوند؛ تصمیم نهایی کارتابل و مجوز `fm_responses` در API کنترل می‌شود.
- نقش‌ها فقط `owner`، `manager` و `club-supervisor` هستند. مدیر می‌تواند پروفایل و فیش را بررسی کند، اما دسترسی عمومی مالی یا مدیریت باشگاه ندارد. سرپرست باشگاه مجوزهای مدیر و مجوزهای باشگاه را می‌گیرد؛ مالک دسترسی کامل دارد.
- حساب وب اعلان‌ها و فرادادهٔ فایل‌های خودش را می‌بیند. دریافت فایل حساب از API وب با `410` متوقف می‌شود؛ تحویل فایل حساب و پیوست محتوای منتشرشده فقط از مسیر بات بله است. پیوست‌های کارتابل برای بررسی مجاز مدیر/سرپرست از API سرور قابل مشاهده‌اند.
- اگر `NORA_WEBAPP_URL` در محیط ربات روی نشانی HTTPS وب‌اپ تنظیم شود، یک دکمهٔ افزودهٔ Mini App در کنار منوی سنتی ظاهر می‌شود. دامنه در کد hardcode نشده و دکمه، منوی قدیمی را جایگزین نمی‌کند.

## مرز اجرای فعلی

- `backend/app.py` برنامهٔ API هم‌مبدأ را ارائه می‌کند. راه‌اندازی عملیاتی به PostgreSQL، migrationها و متغیرهای امن سرور نیاز دارد؛ هیچ راز یا دامنه‌ای در این پوشه ثبت نشده است.
- `server.mjs` پیش‌نمایش امن رابط و اسکلت API است، نه backend عملیاتی؛ `/api/health` آن `server-scaffold` و تحویل بیرونی خاموش را گزارش می‌کند.
- مسیر عمومی `POST /api/outbox` عمداً ارسال انجام نمی‌دهد. این محدودیت، مسیرهای اختصاصی و آزمون‌شدهٔ کارتابل/اعلان/تحویل بات را به ارسال عمومی تبدیل نمی‌کند.
- در محیط فعلی، اتصال عملیاتی به پایگاه تولیدی و توکن‌های بله پیکربندی نشده است؛ پیش‌نمایش نشست یا نقش جعلی نمی‌سازد.

## اجرای رابط پیش‌نمایش

```sh
HOST=0.0.0.0 PORT=4173 node server.mjs
```

برای API واقعی و UI هم‌مبدأ، مراحل نصب PostgreSQL، اجرای migration و تنظیم secretها در `backend/README.fa.md` آمده است. توکن‌ها، گذرواژه‌ها و دادهٔ نشست را در HTML، مرورگر، `localStorage` یا Git قرار ندهید.
