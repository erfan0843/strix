# ممیزی نورا — ۱۹ مهر ۱۴۰۵ / ۱۱ اکتبر ۲۰۲۶

## ۱. خلاصه، دامنه و وضعیت واقعی

**اصلاحات این گزارش در محیط محلی تست شده‌اند؛ محصول آمادهٔ انتشار production اعلام نمی‌شود.** دامنهٔ رسمی، DNS/TLS، دیتابیس اصلی و اتصال زندهٔ ارائه‌دهندگان در اختیار این ممیزی نبودند. هیچ پیام، OTP/SMS یا پرداخت واقعی ارسال نشد.

نورا شامل رابط HTML/JS فارسی، FastAPI/SQLAlchemy/Alembic و ربات بله است. بک‌اند همان فرایندی است که UI و API را میزبانی می‌کند. Strix محصول مستقل انگلیسی با Python 3.12+، viewer مبتنی بر React/TypeScript/Vite و sidecar مبتنی بر Go است؛ زبان، معماری، سورس و static ساخته‌شدهٔ آن بازنویسی نشد. فقط lockfile وابستگی‌های transitive viewer به‌صورت سازگار اصلاح شد.

### شناخت و baseline پیش از اصلاح

- شاخه: `arena/01a0cd72-strix`؛ مبنا: `e158eab3f869a0911f0697e3311f8c47a7625bea`؛ هیچ commit، push، merge یا تغییر history انجام نشد.
- موجودی و SHA-256 برای ۸۵۹ فایل، مسیرهای API، مدل‌های حساب/نشست/فرم/پاسخ، permissions، تنظیمات، manifestها و جریان اجرا بررسی شدند. سه تغییر tracked قبلی کاربر حفظ شدند.
- baseline: ۱۷ suite رابط، ۱۱۱ تست بک‌اند، ۱۰۸ تست ربات و guard مستقل storage موفق بودند. **این موفقیت SQLite، سلامت migration روی PostgreSQL را ثابت نمی‌کرد.**
- خطای واقعی PostgreSQL 16.2 بازتولید شد: revisionهای ۳۳ و ۳۷ کاراکتری در `VARCHAR(32)` با `StringDataRightTruncation` و SQLSTATE `22001` شکست می‌خوردند.
- نصب سرویس‌ورکر در Chromium واقعاً به `redundant` می‌رسید؛ `/event.html` بدون شناسه ۴۰۴ بود و `cache.addAll` را شکست می‌داد.
- ممیزی اولیهٔ axe مشکلات نام کنترل‌ها، کنتراست و تشخیص‌پذیری لینک‌ها را نشان داد. صرف `lang/dir` درست یا وجود `alt` به‌عنوان تأیید accessibility در نظر گرفته نشد.
- type audit اولیه ۱۵۲ finding در ۵۳ فایل داشت؛ ۱۲۲ finding مربوط به سورس برنامه بود. در بررسی نهایی سورس، ۴۰ فایل بدون خطای Mypy بررسی شدند؛ fixtureهای duck-typed آزمون در این نوع‌دهی نیستند و جداگانه اجرا شده‌اند.

## ۳. فارسی‌سازی، RTL، فونت و رفتار محصول

- هر ۱۸ سند مرتبط `lang="fa"` و `dir="rtl"` دارد. متن ثابت و حالت‌های loading/empty/error/auth/owner/member مرور شدند؛ خطای نمایشی Owner API اکنون واژگان فارسی دارد، نه machine code یا exception خام.
- `.code`، HTTP status، payload، route، enum، شناسه، token hash، نام column و تاریخ ذخیره‌شده ترجمه نشدند. `OwnerApiError` همین قرارداد را با پیام انسانی مستقل حفظ می‌کند؛ ۱۲ حالت از 0 تا 503 و کلید `__proto__` تست شدند.
- تغییر i18n سبک است: dictionary پیام و formatterهای موجود؛ وابستگی سنگین ترجمه یا تغییر معماری اضافه نشد. انگلیسی Strix، مجوزهای حقوقی و کد/شناسه‌های فنی به زبان اصلی حفظ شدند.
- formatterهای موجود Persian digits و Jalali/Intl بررسی شدند. شناسه‌های قابل کپی و کدها در بافت لاتین/LTR باقی می‌مانند؛ زمان ISO و مقدار عددی DB بازنویسی نشد.
- کنترل‌های ظرفیت، تعداد، slug و switchهای سازنده/فرمساز label فارسی دارند. dialog بسته `inert/aria-hidden` است، focus در dialog باز مدیریت و سپس بازگردانده می‌شود؛ switchهای span با Space/Enter قابل استفاده‌اند و handler اختصاصی دوبار اجرا نمی‌شود.
- تم واقعی پروژه **light/dark** است. آزمون اولیهٔ تزریق نام نامعتبر `night` با تم واقعی اشتباه گرفته نشد؛ آن harness اصلاح شد و تمام آزمون‌های نهایی روی light/dark واقعی اجرا شدند. اندازه‌گیری کنتراست بعد از تمام‌شدن animationهای محدود انجام شد، نه در فریم fade.
- font-faceهای واقعی و وزن‌ها حفظ شدند؛ هفت فایل WOFF2 تغییر نکردند. Estedad متغیر 100–900، Vazirmatn در وزن‌های 400/500/600/700 و Nora Latin در 400/700 باقی‌اند. برای هر خانواده متن مجوز توزیع اضافه شد؛ شرح و blobهای upstream در `fonts/README.fa.md` است. هفت glyph لاتین برای هر وزن با DejaVu سیستم مطابق بودند؛ metadata مجوز صرفاً از اسم فایل حدس زده نشد. CDP مرورگر نیز `Estedad` و `Vazirmatn UI FD` را با `isCustomFont=true` برای متن/CTA واقعی ثبت کرد، نه فقط font-family اعلامی CSS.
- حساب مهمان همچنان معرفی امکانات واقعی و CTA ورود است. خانه/رویداد/پشتیبانی عمومی‌اند. `#events` مهمان «نیاز به ورود» کوتاه دارد؛ عضو فقط سوابقی را می‌بیند که session وب واقعاً به آن‌ها پیوند خورده است. سوابق قدیمی از روی اسم، تلفن یا Bale ID حدس زده نشدند.
- بله optional باقی ماند؛ Safir همچنان سرویس پیامکی بله است، نه جایگزین حساب/ورود بله. هیچ پیام یا پرداخت واقعی در QA ارسال نشد.

**محدودیت زبان/محصول:** ماژول‌های قدیمی ربات و بعضی امکانات پروفایل/باشگاه/پرداخت هنوز به API وب کامل متصل نیستند؛ این ممیزی آن‌ها را با دادهٔ نمونه «تکمیل» نکرد. exceptionهای قابل نمایش به کاربر در مسیرهای اصلاح‌شده عمومی/فارسی شده‌اند، ولی محتوای خارجیِ ارائه‌دهنده، محتوای authored کاربران و همهٔ مسیرهای legacy اجرانشده، تأیید کامل localization زنده ندارند.

### بازتولید آزمون‌ها

Backend و ربات را در محیط مجازی جدا نصب کنید؛ توکن یا DSN واقعی را در فرمان قابل‌اشتراک/گزارش قرار ندهید. PostgreSQL regression تنها با instance disposable و `NORA_TEST_POSTGRES_URL` تنظیم‌شده اجرا شود؛ هر case schema تصادفی rollback-only دارد. SQLite به‌تنهایی مشکل طول revision را نمی‌گیرد.

### خطاهای میانی و تفکیک آن‌ها

- خطای PostgreSQL، نصب worker، soft404 و accessibility baseline مشکلات **پیشین پروژه** بودند.
- نبود repo root در PYTHONPATH اولیهٔ bot collection، نبود Python/Go مناسب، TLS download failure و warning کتابخانه، ایراد code محصول تلقی نشدند.
- در اصلاح موقت هم‌زمان دو بخش یک فایل، یک suffix اضافی syntax error ساخت؛ پیش از ادامه با SHA-256 دقیقِ baseline فقط تغییر خود ممیزی بازسازی و sequential اعمال شد. هیچ محتوای اصلی حذف نشد؛ syntax و 123 تست نهایی PASS هستند.
- assertهای asset version و policy پیش‌کش قدیمی با cache-bust/policy امن جدید هم‌راستا شدند، نه حذف fixture یا ضعیف‌کردن test. انتظار cookie settings و bootstrap در تست تازه ابتدا اشتباه بود و با قرارداد واقعی source اصلاح شد.
- `support.test.mjs` با delay ثابت 700ms زیر بار موازی flaky بود؛ اکنون resource load/init واقعی را انتظار می‌کشد. 179 assertion نهایی موفق‌اند.
