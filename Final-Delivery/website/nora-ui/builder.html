منبع دادهٔ فرم‌ها روشن است
فقط فرم‌ها و شمار پاسخ‌های دریافت‌شده از API همین سامانه نمایش داده می‌شوند. داده‌های محلی یا نمونه به فهرست و آمار راه نمی‌یابند. پاسخ‌ها با مجوز سروری خوانده می‌شوند؛ اطلاعات به سرویس بیرونی فرستاده نمی‌شود. آمار قیف، تحلیل هر پرسش، خروجی واقعی و گردش پرداخت در این پنل هنوز فعال نیست.
فرم‌ها
روی هر فرم بزنید: اطلاعات، آمار، پاسخ‌دهنده‌ها و تغییرها.
ساخت فرم
هنوز فهرست سروری دریافت نشده است؛ برای دریافت فرم‌ها و شمار پاسخ‌های واقعی، «گرفتن فرم‌های سرور» را بزنید. ورود مالک
هر فرم یک شناسنامه دارد: نوع، پیوند، بازه، ظرفیت، قطعه‌های مالی و پیوندهای پایانی. تنظیمات فرم همیشه آخر همان صفحه است.
گزارش فرم‌ها
وضعیت و پاسخ‌های فرم‌ها در یک نگاه.
فقط فرم‌های API و شمارش پاسخ‌های بازگشتی از FastAPI اینجا جمع می‌شوند؛ نمونه‌های محلی جدا هستند. تحلیل قیف و پاسخ هر پرسش هنوز ارائه نمی‌شود.
