# ربات بله نورا

کد ربات در این پوشه و وب‌اپ در `website/nora-ui/` نگه‌داری می‌شود. این دو از فایل یا محیط نصب مشترک استفاده نمی‌کنند؛ ربات کتابخانه‌های Python خودش را دارد و backend وب‌اپ جدا نصب می‌شود. راه نصب backend در `website/nora-ui/backend/README.fa.md` آمده است.

## نصب محیط ربات

```bash
cd nora_bot
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

`.env.example` فقط جای خالی تنظیمات را نشان می‌دهد؛ توکن‌ها و شناسه‌های واقعی را در secret manager یا محیط محافظت‌شدهٔ همان میزبان بگذارید. فایل `.env` در Git نادیده گرفته می‌شود. نسخهٔ خام تنظیمات آرشیو و فایل‌های داده از آرشیو به این پوشه منتقل نشده‌اند.

## وضعیت اتصال به دادهٔ مشترک

اجرای ربات پیش از دسترسی به API مشترک متوقف می‌شود؛ نقش یا مجوز محلی جای هویت سرور را نمی‌گیرد. کلاینت `shared_api.py` برای نقش سروری، ثبت فرم از گفتگوی بات، تاریخچه و گزارش فقط‌خواندنی پاسخ‌های فرم، کارتابل مشترک پروفایل و فیش، پیوست‌ها، فایل‌های قابل‌دریافت از بات و اعلان‌ها استفاده می‌شود. خطا یا قطع API به fallback محلی در این مسیرها منجر نمی‌شود.

کارتابل پروفایل/فیش، پیوست‌ها، اعلان‌ها و گزارش‌های تجمیعیِ پشتیبانی‌شده از API مشترک خوانده می‌شوند؛ گزارش‌های رویداد، حضور، گواهی و مالی تا ثبت همان داده‌ها در سرور، از SQLite جایگزین نمی‌شوند و صریحاً در دسترس نیستند. ماژول‌های عملیاتی قدیمیِ رویداد، پرداخت و حوزه‌های دیگر هنوز کامل به پایگاه مشترک منتقل نشده‌اند؛ بعضی پاسخ‌های مشترک نیز به‌صورت projection به قابلیت‌های قدیمی بات بازتاب داده می‌شوند. این وضعیت را یکپارچه‌سازی کامل همهٔ داده‌ها یا استقرار زنده تلقی نکنید.

برای اجرای واقعی، `NORA_SHARED_API_URL` و `NORA_BOT_SERVICE_TOKEN` باید در محیط ربات و backend تنظیم شوند؛ توکن در هر دو یکی است و فقط در سرور می‌ماند. پیش از ساخت پایگاه محلی، ربات بررسی می‌کند که `SUPER_ADMIN_ID` همان مالک سروریِ `NORA_OWNER_BALE_USER_ID` باشد؛ تنظیم‌نشدن یا ناهماهنگی این شناسه‌ها اجرای ربات را می‌بندد. `NORA_WEBAPP_URL` نیز اختیاری است: نشانی HTTPS همان وب‌اپ روی دامنهٔ شماست و فقط دکمهٔ افزودهٔ Mini App را به منوی سنتی ربات می‌آورد. منوی گفت‌وگویی فعلی جایگزین نمی‌شود. این الزام‌ها فقط برای اجرای سرویس مستقل ربات‌اند و پیش‌شرط راه‌اندازی FastAPI یا ورود وب نیستند.

فونت‌های ثابت لازم برای گواهی در `files/fonts/` نگه داشته شده‌اند. ساخت گواهی فارسی به پشتیبانی `libraqm` در Pillow نیاز دارد. پایگاه‌ها، پشتیبان‌ها، خروجی‌های Excel، پرونده‌ها، لاگ‌ها و گواهی‌های تولیدشده وارد Git نمی‌شوند.

## آزمون محافظ شروع

```bash
.venv/bin/python tests/test_storage_guard.py
```

این آزمون اطمینان می‌دهد اجرای پیش‌فرض پیش از ساخت SQLite متوقف می‌شود.

## آزمون‌های پایتون

```bash
.venv/bin/pytest -q tests
```

آزمون‌های تابع‌محور با pytest اجرا می‌شوند. تعدادی از آزمون‌های قدیمیِ فازها اسکریپت اجرایی مستقل‌اند و در انتها `sys.exit` دارند؛ برای جلوگیری از اجرای ناخواستهٔ کد هنگام import، pytest آن‌ها را جمع‌آوری نمی‌کند. همان فایل‌ها را فقط با اجرای مستقیم Python اجرا کنید. خود `conftest.py` هیچ منطق اجرایی ربات را تغییر نمی‌دهد.
