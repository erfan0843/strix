# بسته‌ی تحویلی نورا: وب‌سایت + ربات بله

این بسته شامل وب‌سایت نورا (واسط کاربری و API) و ربات بله است. دو بخش جداگانه‌اند ولی یک بک‌اند و یک بخش مشترک (تصویر بلیت) دارند. Strix (پروژه‌ی مستقل انگلیسی) عمداً داخل این بسته نیست.

## ساختار

| پوشه | محتوا |
|---|---|
| `website/nora-ui/` | صفحات HTML/CSS/JS، API با FastAPI، migrationها، تست‌های backend |
| `bale-bot/nora_bot/` | کد ربات بله، `.env.example`، تست‌ها |
| `deployment/` | قالب‌های systemd، Caddy، و نمونه تنظیمات محیط |
| `docs/` | راهنماهای اجرای محلی، استقرار روی دامنه، توکن و امنیت |
| `reports/` | گزارش تست‌ها و وضعیت هر بخش |

## قدم اول
1. `docs/01-اجرای-محلی.fa.md` را بخوانید.
2. برای دامنه و سرور: `docs/02-استقرار-روی-دامنه.fa.md`.
3. برای توکن ربات بله: `docs/03-توکن-و-امنیت.fa.md` (توکن را هرگز در فایل‌های این بسته نگذارید).
4. وضعیت آزمون‌ها و محدودیت‌ها: `reports/گزارش-تست.fa.md`.

## نکات مهم
- هیچ توکن، رمز، شماره‌ی تلفن یا `.env` واقعی در این بسته نیست.
- اجرای محلی روی Python 3.11 تست شده است (لینوکس). اجرای ویندوز تست نشده است.
- اتصال به دامنه‌ی شخصی و پرداخت/OTP واقعی به سرویس‌های بیرونی و اطلاعات شما نیاز دارد و در این محیط آزمایش نشده است.
