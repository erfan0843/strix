# فرم‌سازهای مرجع — چه چیزی از آن‌ها برمی‌داریم

> منابع بررسی‌شده: دیجی‌فرم، فرم‌افزار، پُرس‌آل، ایپُل، یوچک، فرم‌ساز نورا (داخل کد تحویلی) و در سطح جهانی: Typeform، Tally، Jotform، Fillout، Paperform، Google Forms.
> جمع‌بندی هر کدام در یک خط، بعد مدل‌شان، بعد آنچه برمی‌داریم و آنچه دور می‌ریزیم.

---

## ۱) هر مرجع، یک درس

| مرجع | درس اصلی |
| --- | --- |
| **دیجی‌فرم** | آزمون جدی است: احراز تصویری، فیلم گرفتن از کاربر حین آزمون، تختهٔ آنلاین، تصحیح خودکار، بلیت و **صدور گواهینامه** از دل فرم. |
| **فرم‌افزار** | «ابزارک»: بیش از ۳۰ ابزار + پنل/مرحله، فیلد رزرو وقت، **فیلد فرم** (فرم را به فرم وصل می‌کند)، محاسبه‌گر (جمع/میانگین/کم/بیش)، لیست‌های آماده، ذخیرهٔ فیلترها، دانلود دسته‌جمعی پیوست‌ها، خروجی PDF/JPG/TIFF/اکسل با قالب چاپ. |
| **پُرس‌آل** | پرسشنامهٔ حرفه‌ای: ۱۷ نوع سوال، **پایپینگ** (آوردن پاسخ قبلی در متن سوال بعد)، امتیازدهی به گزینه، سوال گروهی، تصویر در متن سوال، QR، نمودار، پیامک پایان. |
| **ایپُل** | ۳۲ قالب آمادهٔ سوال، ویرایشگر HTML در متن سوال، شرط‌گذاری، امتیازدهی، صافی‌های پیشرفته در نتایج. |
| **یوچک** | سادگی پنل: صفحه‌بندی سوالات، چندزبانه، لوگو و پس‌زمینه، قاعدهٔ شرطی، ایمیل خودکار، اتصال به پنل پیامک و ایمیل. |
| **فرم‌ساز نورا (کد خودمان)** | ۹ نوع فرم، ۷۸ نوع فیلد، ۸ عملگر شرط، دو حالت پر کردن (دونه‌دونه / همه‌یک‌جا)، چهار سطح دسترسی، چرخهٔ تأیید پاسخ، کارنامهٔ هر سوال، اتصال به رویداد/پرداخت/بلیت/گواهینامه/آیدی‌کارت/وبهوک، کد پیگیری و QR. |
| **Tally** | ویرایشگر بلوکی، شبیه نوشتن در یک دفتر: هر بلوک یک سوال، «+» بین بلوک‌ها، دستور با «/»، **پاسخ نیمه‌کاره** ذخیره می‌شود. |
| **Typeform** | یک سوال در هر صفحه؛ بالاترین نرخ تکمیل. بلوک‌های «بیانیه» و «خوش‌آمد» بین سوال‌ها، جهش منطقی، ماشین‌حساب. |
| **Jotform** | انبار قالب (۱۰٬۰۰۰+)، **گردش کار تأیید چندمرحله‌ای**، ساخت PDF از پاسخ، امضای الکترونیک. |
| **Fillout** | همگام‌سازی دوطرفه با جدول بیرونی، بلوک زمان‌بندی (نوبت‌دهی)، CSS سفارشی، صافی و دیدگاه جدولی. |
| **Paperform** | فرم مثل یک صفحهٔ مقاله؛ محاسبه‌گر و محصول داخل فرم. |
| **Google Forms** | بخش‌بندی، اعتبارسنجی پاسخ، حالت آزمون. |

## ۲) مدل ساخت فرم — چهار الگو، انتخاب ما

| الگو | کی خوب است | مشکلش |
| --- | --- | --- |
| چت‌محور (نورا فعلی) | بدون نصب، همه‌جا در دسترس | کور است؛ نه جابه‌جایی، نه پیش‌نمایش، نه جدول |
| پنل کلاسیک (Jotform) | پر از امکان | سنگین، شلوغ، ترسناک |
| **بلوکی/دفتری (Tally)** | سریع، خوانا، طبیعی | باید تازه ساخته شود |
| گفتگویی (Typeform) | نرخ تکمیل بالا | برای پرسشنامهٔ طولانی خسته‌کننده |

**تصمیم ما: بلوکی برای ساخت + گفتگویی برای پر کردن.**
یعنی کارشناس فرم را مثل یک دفتر می‌چیند (بلوک روی بلوک)، و کاربر آن را یک‌سوال‌درهرصفحه می‌بیند.

سازندهٔ ما شش کار می‌کند، نه بیشتر:
۱) افزودن سوال (از کاتالوگ گروه‌بندی‌شده) ۲) نوشتن عنوان و راهنما در جای خودش ۳) جابه‌جایی با دستگیره ۴) شرط روی همان بلوک ۵) تنظیمات در ورقهٔ کنار ۶) پیش‌نمایش زندهٔ همان لحظه.

---

## ۳) کاتالوگ سوال — اجماع همهٔ مراجع، پالایش‌شده

۷۸ نوع فعلی نورا برای مدیر زیاد است. این ۳۴ نوع بس است؛ بقیه از همین‌ها ساخته می‌شود.

| گروه | سوال‌ها |
| --- | --- |
| نوشتاری (۵) | کوتاه · بلند · تشریحی · عدد · مبلغ |
| انتخابی (۵) | تک‌انتخاب · چند‌انتخاب · کشویی · بله/خیر · تصویر‌انتخاب |
| پروفایل (۵) | نام و نام خانوادگی · موبایل (+تأیید کد) · کد ملی · تاریخ تولد · جنسیت |
| تماس (۳) | ایمیل · آدرس · استان و شهر |
| زمان (۴) | تاریخ شمسی · ساعت · تاریخ و ساعت · **نوبت (رزرو وقت)** |
| رسانه (۴) | تصویر · فایل/سند · صدا · امضا |
| سنجه (۳) | ستاره · ۰ تا ۱۰ · **نمودار میله‌ای** |
| مالی (۳) | انتخاب قیمت‌دار · کد تخفیف · پرداخت |
| مقررات (۱) | پذیرش قوانین |
| ويژه (۱) | موقعیت مکانی |

هر سوال این تنظیمات را دارد: عنوان · راهنما · اجباری · پیش‌فرض · حد کم/زیاد · قالب مجاز · پیشنهاد از پروفایل · شرط · ستون‌شدن در خروجی.

## ۴) مدل منطق — چیزی که همه دارند و ما کامل می‌خواهیم

| توان | توضیح |
| --- | --- |
| شرط نمایش | اگر [سوال] [عملگر] [مقدار] → نشان بده |
| پرش/جهش | بعد از این سوال برو به سوال n یا «پایان» |
| مرحله | گروه‌بندی چند سوال در یک مرحله با نوار پیشرفت |
| پایپینگ | آوردن پاسخ قبلی در متن سوال، گزینه یا پیام پایان: «{نام} عزیز…» |
| امتیاز | هر گزینه امتیاز؛ جمع خودکار، نمرهٔ قبولی، نمرهٔ منفی |
| ماشین‌حساب | جمع/تفریق/درصد روی فیلدها (مثل فاکتور) |
| نیمه‌کاره | ذخیره در هر لحظه، ادامه با همان لینک |
| تکرارشونده | بخش تکرارشو برای «اعضای خانواده»، «اقلام سفارش» |
| فیلد پنهان | مقدار از لینک (`?src=instagram`) داخل پاسخ می‌نشیند |

قاعدهٔ ایمنی (از نورا می‌آید و می‌ماند): سوال شرطی **بعد از** سوال شرط می‌آید؛ سیستم جای خلافش را نمی‌دهد.

## ۵) مدل دسترسی و کارشناس

| مرجع | نکتهٔ قابل برداشت |
| --- | --- |
| نورا | چهار سطح: عمومی · لینک · بخش · خصوصی (کد/افراد). سه نقش: مالک · ویرایشگر · بیننده. |
| Jotform | گردش کار تأیید: پاسخ → کارشناس یک → کارشناس دو → تأیید نهایی. |
| فرم‌افزار | سطوح دسترسی به خودِ فرم و به اطلاعات ثبت‌شده، جدا. |

**تصمیم:** پنج مجوز سرورساید (`ساخت · ویرایش · دیدن پاسخ · خروجی · حذف`) + نقش «کارشناس این فرم» جدا از «کارشناس سازمان». کارشناس فقط پاسخ‌های سپرده‌شده را می‌بیند.

---

## ۶) مدل خروجی و پول

| خروجی | نکته‌های برداشتنی |
| --- | --- |
| پیام تأیید | ایمیل/پیامک/پیام‌رسان، با متن قابل ویرایش و کد پیگیری |
| بلیت | دیجی‌فرم بلیت الکترونیک با بارکد می‌دهد؛ ما QR + کد پیگیری + افزودن به تقویم. |
| گواهینامه | دیجی‌فرم و پُرس‌آل از دل آزمون صادر می‌کنند؛ ما با کد استعلام عمومی. |
| فایل | اکسل (ستون هر سوال) · PDF/JPG از قالب چاپ · دانلود دسته‌جمعی پیوست‌ها. |
| پرداخت | درگاه مستقیم (زرین‌پال، پی‌پینگ، زیبال، مهرکارت، ملت) + کارت‌به‌کارت با رسید + کیف پول + اقساط. |
| پیام | پنل‌های پیامک ایرانی (رهیاب، فراپیامک، قاصدک، رادکام، فراز اس‌ام‌اس) به‌صورت اتصال اختیاری. |

قاعدهٔ ما: **مبلغ از جیب کاربر تا تأیید کارشناس، سه جا ثبت می‌شود** (پاسخ، تراکنش، رسید) و مغایرت شبانه گزارش می‌شود.

---

## ۷) چه چیزی را عمداً برنمی‌داریم

| نمی‌گیریم | چرا |
| --- | --- |
| انبار قالب (۱۰٬۰۰۰+) | شلوغی و انتخاب سخت؛ جایش ۹ نوع فرم + کپی از فرم موجود. |
| تولید فرم با هوش مصنوعی | حس «ساختهٔ ماشین» می‌دهد؛ ما دست‌ساز و دقیق می‌خواهیم. |
| قیمت‌گذاری به‌ازای هر پاسخ | برای سازمان ما معنا ندارد؛ پلن ثابت. |
| ۷۸ نوع سوال در منوی اصلی | کاتالوگ ۳۴ نوع، با ساخت بقیه از همین‌ها. |
| شیشه روی همه‌چیز | شیشه فقط لایهٔ ناوبری؛ محتوا مات و خوانا. |
| افکت‌های چشم‌نواز بدون کار | هر جلوه باید معنا داشته باشد. |
| متن‌های طولانی راهنما | کاربر حدس می‌زند؛ راهنما کوتاه، در جای خودش. |

---

## ۸) نتیجه در یک نگاه

```
ساخت:  بلوکی، دفتری، با دستگیره و «+» بین سوال‌ها
پر کردن: دونه‌دونه، گفتگویی، با ذخیرهٔ نیمه‌کاره
دسترسی: پنج مجوز + کارشناس مخصوص هر فرم
خروجی:  پیام · بلیت · گواهینامه · اکسل/PDF · وبهوک
پول:    درگاه، کارت‌به‌کارت، کیف پول، اقساط — با محافظ سقف و کف
زبان:   فارسی روان تهرانی، کوتاه، بدون شعار
ظاهر:   شیشهٔ مایع فقط روی ناوبری؛ محتوا آرام و مات
```
